# 知客 ZhiKe AI：W3 Agent Demo 演示脚本

## 1. 文档目的

本脚本用于 W3 半决赛的现场演示、录屏与交叉评测。演示重点不是展示单次文本生成，而是证明知客能够把已有 Skills 整合为可交互的业务 Agent：业务员设定目标、处理客户信息、确认跟进结果，并获得可追溯的 KPI 进度与行动建议。

## 2. 演示前检查

1. 启动 `streamlit run app.py`，或打开已部署的演示地址。
2. 检查页面显示“W3 Agent Demo”。
3. 默认使用已配置的 MiniMax API；如接口暂不可用，开启“强制使用 Mock 演示模式”。Mock 模式可完整验证交互、KPI 与容错逻辑，但不应被表述为真实模型输出。
4. 说明数据边界：本次演示不使用数据库，客户状态与 KPI 仅在当前浏览器会话内保存。

## 3. 建议演示时长：5—7 分钟

| 时间 | 操作 | 向评审说明的价值 |
|---|---|---|
| 0:00—0:40 | 介绍项目定位与 7 个 Skills 客户处理链 | 知客不是聊天机器人或 CRM，而是面向业务动作的 Agent。 |
| 0:40—1:20 | 在页面直接可见的“本次会话目标 / Session Goals & KPI”区设置本周目标 | 业务员先定义目标，Agent 的后续建议有明确业务方向。 |
| 1:20—2:30 | 选择案例 1，点击“生成业务报告” | 展示非结构化记录进入结构化档案、分析、判断、建议和话术；同时展示 7 步 Skills 执行轨迹。 |
| 2:30—3:20 | 打开“业务日报”页 | 展示 W2 的跨客户 Mock 日报能力及其演示边界。 |
| 3:20—4:30 | 打开“🎯 KPI 与行动”页，查看初始 KPI 与优先行动 | 说明此时 KPI 为 0 是正确设计：报告生成不等于业务结果。 |
| 4:30—5:30 | 为当前客户记录“已完成一次有效沟通”或“已确认客户关键需求” | 展示 KPI 只根据人工确认的反馈更新，避免模型虚构业绩。 |
| 5:30—6:30 | 再次查看 KPI、风险提示和行动队列 | 展示客户处理结果如何回流到目标与下一步行动。 |

## 4. 推荐演示数据

### 4.1 业务目标

| 指标 | 建议设定值 |
|---|---:|
| 目标周期 | 本周 |
| 剩余工作日 | 3 |
| 新增合格客户 | 3 |
| 有效沟通 | 5 |
| 方案沟通 / 演示 | 2 |
| 重点客户推进 | 2 |

### 4.2 客户案例

优先使用页面内置的“案例 1 · 企业培训客户”：李总对 AI 业务助理感兴趣，希望下周进行线上沟通，但预算、部署要求和实际使用条件尚待确认。

### 4.3 跟进反馈

按演示节奏依次记录：

1. **已完成一次有效沟通**：模拟已与李总确认下周沟通窗口。
2. **已确认客户关键需求**：模拟已确认客户希望先看销售跟进场景和部署方式。
3. 可选：**已完成方案沟通/演示**，展示方案沟通目标随人工确认而更新。

不要把模型建议直接作为反馈提交；反馈必须代表业务员已经确认发生的真实或演示事件。

## 5. 关键讲解话术

### 5.1 为什么不是把 KPI 做成普通仪表盘？

“知客的 KPI 不用于考核员工，也不要求用户手工维护一张表。它把客户处理后的下一步动作与业务目标关联起来：哪些客户该优先联系、哪些目标仍有缺口、今天先做什么。它服务于业务行动，而不是展示数字。”

### 5.2 为什么 KPI 数字可信？

“KPI 计算不调用模型。模型负责生成可供参考的分析与建议；只有业务员确认的跟进反馈才会写入当前会话状态并改变计数。因此每项数字都可回溯到一个确认事件。”

### 5.3 W3 与 W2 的区别是什么？

“W2 重点验证从客户输入到业务报告的 Skills 工作流。W3 将这些 Skills 封装到可交互 Agent 中，再加入业务目标、反馈回写和 KPI 行动调整，使其形成可演示的业务闭环。”

## 6. 异常情况下的演示策略

| 情况 | 处理方式 |
|---|---|
| 外部模型接口不可用 | 开启 Mock 演示模式；本地 Skills Pipeline 与 KPI 反馈闭环仍可运行。 |
| 模型输出字段不完整 | 系统保留 W2 的本地 Skills 回退机制；展示结果前确认 7 个输出标签可用。 |
| 页面刷新后 KPI 清空 | 向评审说明这是当前无数据库、仅会话内演示的明确边界；重新按脚本录入目标与反馈。 |

## 8. 边界说明

本演示不声称已完成真实 CRM、多用户协作、跨会话客户记忆、微信自动读取或企业级部署。它验证的是 W3 阶段 Agent 的交互方式、Skills 整合、确定性 KPI 计算与行动辅助价值。
